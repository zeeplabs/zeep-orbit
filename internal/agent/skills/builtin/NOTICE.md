# Built-in skills: provenance and attributions

Every built-in skill under this directory is authored or adapted for the Zeep
Orbit AI Builder (React + Vite + TypeScript + plain CSS + `HashRouter`, with
the builder's own tools).

No third-party text is included yet. When a built-in adapts third-party
material, list it here before merging: the skill name, the upstream source,
its license (verified from the upstream repository), and what was changed.
Anything without a clear permissive license is written from scratch instead.
