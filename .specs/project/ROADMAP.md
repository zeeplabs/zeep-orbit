# Roadmap

## M1 — MVP Core ✅ complete

**Goal:** Schema YAML → REST API running on your PostgreSQL. CLI-driven. Docker Compose deploy.

Features:

- [x] Config loader (apps.yaml)
- [x] Schema parser + validation
- [x] PostgreSQL schema provisioning (CREATE/ALTER TABLE)
- [x] Auto REST CRUD per table (GET, POST, PUT, DELETE, GET/:id)
- [x] JWT auth middleware per app
- [x] HTTP reverse routing by app name
- [x] CLI: `zeep apply`, `zeep list`, `zeep status`
- [x] Docker Compose deploy (zeep-orbit + PostgreSQL)
- [x] Basic query params: `?limit=`, `?offset=`, `?{field}=eq.{value}`

**Done when:** A frontend generated by an AI tool can define a schema, run `zeep apply`, and make authenticated REST calls against its own schema on company PostgreSQL — all in under 10 minutes.

---

## M2 — Developer Experience ✅ complete

- [x] TypeScript SDK (`@zeeptech/orbit-client`) — plus Go, Python, Rust, Java, PHP clients, all published
- [ ] Official prompt snippets for Claude Code / Cursor / Lovable
- [ ] MCP server for zeep-orbit operations
- [x] Web dashboard (app catalog, schema viewer, logs, data browser, SDKs page, API tab)
- [ ] Helm chart / Kubernetes deploy
- [x] Schema migrations (alter existing tables safely)
- [x] Filtering: `?{field}=gt.{value}`, `in.`, `like.`
- [x] Sorting: `?order={field}.asc`
